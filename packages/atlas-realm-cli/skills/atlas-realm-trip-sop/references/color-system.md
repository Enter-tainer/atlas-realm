# 配色 SOP（Atlas Realm 行程房间）

> 提炼自实际路书房间的做法，并用 CIEDE2000 实测验证。

## 1. 色板来源

**只用 Tailwind CSS 默认调色板；深浅只在同族内跳 2 档（`-400` ↔ `-600`，加密时 `-400` ↔ `-700`）。禁止自定义 hex、禁止渐变。**
样例房间 12 个色值 100% 命中 Tailwind 默认板——这不是巧合，是可直接继承的标准。

```
#3b82f6 blue-500      #2563eb blue-600     #8b5cf6 violet-500   #a78bfa violet-400
#ec4899 pink-500      #f59e0b amber-500    #f97316 orange-500   #06b6d4 cyan-500
#10b981 emerald-500   #84cc16 lime-500     #ef4444 red-500      #0ea5e9 sky-500
```

## 2. 分配优先级：先语义 → 再单元 → 最后专题

### ① 语义色：默认「不设色」

原则是 **一色一义**：颜色只编码「阶段（天/岛）」，其他语义用 emoji + label + 线型编码。

| 语义               | 处理                                                                                              |
| ------------------ | ------------------------------------------------------------------------------------------------- |
| 住宿 / 营地        | 继承当天单元色 + `🏨`（反例：给住宿单配 violet-400，与 Day2 violet-500 只差 ΔE13 → 被读成同一天） |
| 机场 / 港口 / 车站 | 继承当天单元色 + `✈️`/`⛴️`/`🚌`                                                                   |
| 取车 / 还车        | 继承当天单元色 + `🚗`/`🔑`                                                                        |
| 警示 / 事故地      | 继承当天单元色 + `⚠️`；唯一破例色 `#ef4444` red-500，全房间只此一色                               |

若确实需要一个“色带之外”的基础设施色，全房间只允许 **1 个**，且与色带每一档 **ΔE ≥ 20**。

### ② 单元色：「同族成对 + 色相递进」

1. 相邻两天 **共用同一色相**（同系列）；**深度拉开 2 档**（`-400` ↔ `-600`）→ 可辨。
2. 每跨一对，**色相前进一族**（blue → violet → pink → amber）→ 看得出行程在推进。
3. 单元多、需要更强区分时，深度改跳 3 档（`-400` ↔ `-700`）。

### ③ 专题色

专题层也是「一个单元」，同样占用色带里的一档（接在最后一天之后继续走），**不另开色相**。自然/花田类可整体用同一档。

## 3. 实测（CIEDE2000，可辨阈值判定）

| 方案                              | 相邻最小 ΔE | 结论              |
| --------------------------------- | ----------- | ----------------- |
| 单色同族 · 连续档（blue-300→900） | 5.4         | ✗ 看不出第几天    |
| 相邻色相逐档（sky→rose）          | 5.0         | ✗ 紫/紫罗兰分不出 |
| 相邻色相跳一档                    | 12.1        | △ 勉强            |
| **同族成对 · 跳 2 档（推荐）**    | **16.2**    | ✓                 |
| 同族成对 · 跳 3 档（加密）        | 24.2        | ✓ 最强            |
| （参考）样例房间现状 Day1→Day2    | 18.4        | 基线：“一眼可辨”  |
| （参考）样例房间 住宿 → Day2      | 13.2        | ✗ 撞色            |

**判定线**：相邻 ΔE ≥ 15 一眼可辨 · 12–15 勉强 · **< 12 视为同色**。同系列 = 同族或色相跨度 ≤ 75°。

## 4. 默认色带（8 单元）

```
Day1 blue-400   #60a5fa   Day2 blue-600   #2563eb
Day3 violet-400 #a78bfa   Day4 violet-600 #7c3aed
Day5 pink-400   #f472b6   Day6 pink-600   #db2777
Day7 amber-400  #fbbf24   Day8 amber-600  #d97706
```

超过 8 个单元：沿色环继续（fuchsia → rose → orange → …），或回本族 `-300/-800` 再走一圈。
族序按行程主轴选起点（海/冷 → blue；山/高原 → violet；花田/森林 → emerald；荒野 → amber），**起点可变、规则不变**。

## 6. 校验清单

- [ ] 相邻单元跑 CIEDE2000：最小 ΔE **≥ 15**，色相差 ≤ 75°
- [ ] 所有色值能在 Tailwind 默认板里找到，且**同一档位不重复使用**
- [ ] 抽查任意点：颜色 == 其所属单元色（不做单独挑色）
- [ ] 住宿/机场/港口等语义要素颜色 == 当天单元色，仅靠 emoji 区分
- [ ] dashed 段用同色相 + 低 opacity，而非新色相
- [ ] 色带示意（D1-Dn 色块）附在计划文档或房间说明里
- [ ] 一致性优先级：可辨性 > 同系列感 > 减少色数 > 美观
